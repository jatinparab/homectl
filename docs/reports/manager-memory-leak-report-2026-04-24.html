Implemented Fixes

1) Agent link pending lifecycle hardening

  • Added explicit pending-entry cleanup helpers on peer (removePending, closeAllPending).
  • Closed pending channels when Done=true is processed.
  • Closed all pending channels on peer disconnect.
  • Removed buffered-forwarder path from requestAgent; callers now handle first-message timeout directly.
  • Added unary cleanup defer so non-Done responses do not leak map entries/channels.

2) WebSocket memory pressure reduction

  • Split outbound websocket queues into:
    • state channel: 1-slot conflated latest snapshot
    • stream channel: buffered queue preserving log/stream messages
  • This prevents state backlog growth while avoiding stream line loss.

3) Secondary memory-growth cleanup

  • Coalesced prune-state persistence writes via single in-flight background saver (requestPruneStateSave).
  • Pruned stale entries from pruneState and pendingGlobalRestores in assignment resolution.
  • Deduped QuarantinedOn during migration to avoid unbounded duplicate growth.
